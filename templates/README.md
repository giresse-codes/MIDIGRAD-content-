# templates/ — Gabarits visuels

**Rôle :** gabarits réutilisables (Canva, Photoshop, Figma…) pour produire vite et de façon cohérente.

| Dossier | Contenu | Formats à prévoir |
|---|---|---|
| `verset/` | Verset du jour | 1080×1350 (4:5), 1080×1080 (1:1), 1080×1920 (9:16) |
| `citation/` | Paroles de l'Apôtre / de prédication | 1080×1350, 1080×1920 |
| `annonce-culte/` | Annonce du culte, événements | 1080×1350, 1080×1920, 1200×630 (Facebook) |
| `miniature-youtube/` | Miniatures | 1280×720 (16:9) |

**Mode d'emploi**
1. Dupliquer le gabarit, ne jamais modifier l'original.
2. Remplacer uniquement les zones de texte / photo prévues ; garder couleurs et polices de `brand/charte.md`.
3. Exporter en PNG (ou JPG qualité ≥ 90) avec le nom `AAAA-MM-JJ_type_titre` (voir `CLAUDE.md`).
4. Mettre dans chaque sous-dossier le fichier source (ou le lien Canva dans un `lien.txt`) et un aperçu `apercu.png`.

**Règles communes :** logo (icône ou horizontal) en bas, référence biblique toujours visible,
texte ≤ 25 mots sur les visuels de verset, marges de sécurité de 80 px (zones d'interface TikTok/Reels en bas et à droite).
