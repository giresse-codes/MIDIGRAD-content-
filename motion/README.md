# motion/ — Motion design

**Rôle :** projets d'animation (After Effects, CapCut, Premiere, DaVinci…) et leurs exports.

| Dossier | Contenu | Durée cible |
|---|---|---|
| `intro/` | Générique d'ouverture (logo animé) | 3–5 s (court) / 8–10 s (YouTube) |
| `outro/` | Fin : abonnement, réseaux, verset | 5–15 s |
| `versets/` | Animation de versets (texte cinétique) | 10–30 s |

**Mode d'emploi**
1. Un sous-dossier par projet : `AAAA-MM-JJ_motion_titre/` avec `source/`, `export/`, `notes.md`.
2. Exporter en MP4 H.264 ; version 16:9 (1920×1080) et 9:16 (1080×1920) si utile ;
   version avec fond transparent (ProRes 4444 / MOV) pour l'intro et le filigrane.
3. Principes : mouvements doux et lumineux (l'or = la lumière de la grâce), croix rouge qui apparaît
   en dernier, pas d'effets agressifs. Musique libre de droits ou avec autorisation.
4. Ne pas versionner les gros fichiers de rendu dans Git : garder les exports lourds sur le Drive
   et noter le lien dans `notes.md`.
