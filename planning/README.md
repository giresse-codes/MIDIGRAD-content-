# planning/ — Calendrier éditorial

**Rôle :** organiser quoi publier, quand, sur quelle plateforme et qui s'en charge.

| Fichier | Rôle |
|---|---|
| `rythme-hebdomadaire.md` | Le rythme de publication de la semaine type |
| `checklist-publication.md` | Vérifications obligatoires avant chaque publication |
| `modele-calendrier.md` | Modèle de calendrier à dupliquer chaque mois |
| `calendrier/` | Calendriers mensuels remplis (`AAAA-MM_calendrier.md`) |

**Mode d'emploi**
1. Chaque fin de mois, dupliquer `modele-calendrier.md` dans `calendrier/` pour le mois suivant.
2. Le remplir à partir de la prédication du dimanche (voir `contenus/`).
3. Cocher la `checklist-publication.md` avant chaque mise en ligne.
