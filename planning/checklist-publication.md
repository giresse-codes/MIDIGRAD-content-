# Check-list avant publication

## Fond
- [ ] Citation biblique vérifiée mot pour mot (référence + version indiquées).
- [ ] Parole de l'Apôtre Paris Talla vérifiée contre l'enregistrement, non reformulée.
- [ ] Message respectueux, chaleureux, centré sur la grâce.
- [ ] Orthographe et accents relus (FR), traduction relue (EN si présente).

## Forme
- [ ] Bon format pour la plateforme (voir `CLAUDE.md`).
- [ ] Couleurs et polices conformes à `brand/charte.md` ; logo présent et non déformé.
- [ ] Texte dans les zones de sécurité (pas caché par l'interface TikTok/Reels).
- [ ] Vidéo : son clair, sous-titres synchronisés, pas de coupure brutale.
- [ ] Musique / images libres de droits ou autorisées ; accord des personnes filmées.

## Publication
- [ ] Fichier nommé `AAAA-MM-JJ_type_titre`.
- [ ] Légende rédigée + appel à l'action + 3 à 5 hashtags (#MIDIGRAD #Grâce #Jésus …).
- [ ] Liens vérifiés (YouTube, direct, adresse).
- [ ] Miniature / couverture choisie.
- [ ] Calendrier mis à jour (statut « Publié » + lien).

## Après publication (24–48 h)
- [ ] Répondre aux commentaires avec bienveillance.
- [ ] Noter vues / partages dans le calendrier.
