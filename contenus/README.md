# contenus/ — De la prédication aux publications

**Rôle :** transformer chaque prédication en une série de contenus pour toutes les plateformes.

| Fichier / dossier | Rôle |
|---|---|
| `systeme-production.md` | Le processus complet, étape par étape |
| `modele-fiche-predication.md` | Fiche à remplir pour chaque prédication |
| `predications/` | Une fiche par prédication : `AAAA-MM-JJ_predication_titre.md` |

**Mode d'emploi**
1. Après le culte, copier `modele-fiche-predication.md` dans `predications/`.
2. Remplir la fiche (thème, versets, citations fortes, timecodes).
3. Suivre `systeme-production.md` pour produire les déclinaisons, puis les planifier dans `planning/`.
