# videos/ — Vidéos : scripts, sous-titres, montage

**Rôle :** tout ce qui prépare et documente les vidéos (pas les rushs eux-mêmes, trop lourds pour Git).

| Dossier | Contenu |
|---|---|
| `scripts/` | Scripts et découpages (`AAAA-MM-JJ_script_titre.md`) |
| `sous-titres/` | Fichiers `.srt` FR (et EN si disponible) |
| `notes-montage/` | Notes de montage : timecodes, extraits choisis, retouches |

**Mode d'emploi**
1. Pour chaque prédication filmée, créer une note de montage avec les timecodes des extraits.
2. Sous-titres : relire **chaque** citation biblique contre la Bible de référence et chaque parole de
   l'Apôtre contre l'enregistrement avant export.
3. Standards de qualité : son nettoyé (réduction de bruit, normalisation à −14 LUFS), étalonnage
   simple et chaleureux, sous-titres incrustés sur les formats verticaux.
4. Rushs et exports finaux : stockés sur le Drive, lien noté dans la note de montage.
