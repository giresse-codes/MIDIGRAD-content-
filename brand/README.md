# brand/ — Identité visuelle

**Rôle :** source unique de vérité pour l'identité MIDIGRAD (logo, couleurs, polices, charte).

| Élément | Emplacement |
|---|---|
| Logo d'origine (référence) | `logo-original.png` |
| Déclinaisons du logo | `logo/` |
| Fichiers de polices / liens | `polices/` |
| Charte graphique | `charte.md` |

**Mode d'emploi**
1. Avant toute création, relire `charte.md`.
2. Ne jamais déformer, recolorer ou recadrer le logo hors des déclinaisons validées.
3. Toute nouvelle déclinaison est exportée en PNG transparent + SVG dans `logo/`,
   nommée `midigrad_logo_<declinaison>_<couleur>.<ext>` (ex. `midigrad_logo_icone_blanc.png`).
